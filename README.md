# LovkoTech — змагання і фестивалі з чесним суддівством

Прототип платформи для подій із журі: інженерні перегони, латте-арт фестивалі, хакатони, робототехніка.
Регламент → реєстрація → суддівство з відкритим протоколом → апеляції → результати → рейтинг сезону.

Команда STU-067 (Youthquake, Дія.Бізнес): Рябко Ілія, Дьякова Аделіна · НТУ «Дніпровська політехніка».

## Що всередині

| Шлях | Що це |
|---|---|
| `index.html` | Прототип платформи (один файл, без збірки). Дані демо, дії відвідувача зберігаються в його браузері |
| `racing/` | Розширений модуль перегонів: траси, конструктори, виробники, голосування за місце етапу |
| `functions/api/feedback.js` | Cloudflare Pages Function: прийом відгуків (`POST`) і експорт для команди (`GET` з ключем) |
| `functions/api/feedback/stats.js` | Публічна агрегована статистика: кількість відгуків, середня оцінка, відповіді «чи довіряли б протоколу» |
| `_headers` | Заголовки безпеки для Cloudflare Pages |

**Зворотний зв'язок у прототипі:** кнопка «★ Оцінити прототип» на кожному екрані (оцінка 1–5, роль, коментар, екран підставляється автоматично) і питання «Чи довіряли б ви результатам із таким протоколом?» на вкладці «Протокол». Якщо сервер недоступний, відгук чекає в черзі браузера й надсилається пізніше.

**Сталий елемент (етика):** регламент фіксується до старту з відбитком SHA-256 і кнопкою перевірки; протокол лише доповнюється (виправлення й скасування — нові записи з автором, часом і причиною); апеляції публічні; протоколи лише цифрові.

## Розгортання на Cloudflare Pages

1. **Cloudflare → Workers & Pages → Create → Pages → Connect to Git** (Import an existing Git repository), оберіть репозиторій `LovkoTech`.
2. Налаштування збірки: *Framework preset* — **None**, *Build command* — порожньо, *Build output directory* — `/`. Натисніть **Save and Deploy**. Папку `functions/` Cloudflare підхопить сам.
3. **Сховище для відгуків:** Storage & Databases → **KV** → Create namespace `lovkotech-feedback`.
4. У проєкті Pages → **Settings → Bindings → Add → KV namespace**: *Variable name* `FEEDBACK`, namespace `lovkotech-feedback` (для Production; за бажання — і для Preview).
5. **Settings → Variables and Secrets → Add**: тип *Secret*, назва `ADMIN_KEY`, значення — довгий випадковий пароль.
6. **Deployments → … → Retry deployment**, щоб прив'язки запрацювали.

Перевірка: відкрийте `https://<проєкт>.pages.dev/api/feedback/stats` — має бути `"configured":true`.

**Вивантажити відгуки:** `https://<проєкт>.pages.dev/api/feedback?key=<ADMIN_KEY>&format=csv`

## Локальний запуск

```bash
npx wrangler pages dev . --kv FEEDBACK --binding ADMIN_KEY=test-key
```

Без Cloudflare (наприклад, на GitHub Pages) прототип теж працює, лише відгуки лишаються в черзі браузера.
